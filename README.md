🛒 О проекте «Северяночка»
«Северяночка» — это современный и отзывчивый интернет-магазин, разработанный для демонстрации навыков создания удобных и высокопроизводительных веб-интерфейсов (e-commerce).

Проект представляет собой полноценную фронтенд-реализацию онлайн-супермаркета, где пользователь может комфортно находить товары, управлять корзиной и знакомиться с актуальными предложениями.

✨ Ключевой функционал:
Интуитивный каталог: Удобная навигация по категориям товаров, продуманные карточки продуктов с индикацией скидок и рейтингов.

Динамическая корзина: Интерактивное добавление товаров, пересчет стоимости в реальном времени и управление количеством.

Адаптивный дизайн: Интерфейс полностью оптимизирован под любые устройства — от мобильных телефонов до широкоформатных мониторов.

Современный стек: При разработке использовались передовые фронтенд-технологии для обеспечения быстрой загрузки и плавности интерфейса.
