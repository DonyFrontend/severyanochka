# Северяночка — страница «Избранное»

Точная верстка страницы избранного: header с поиском, чипы фильтров, сетка карточек товаров, пагинация и футер. Полностью рабочая — без внешних зависимостей и картинок из интернета (все иконки/картинки — встроенный SVG).

## Как открыть в VS Code

1. Распакуйте папку `severyanochka` и откройте её в VS Code (`Файл → Открыть папку…`).
2. Установите расширение **Live Server** (автор ritwickdey) из вкладки Extensions, если его ещё нет.
3. Кликните правой кнопкой по `index.html` → **Open with Live Server**.
   - Страница использует `import/export`, поэтому открывать через Live Server надежнее, чем двойным кликом по HTML.

## Что работает

- Поиск — фильтрует карточки по названию в реальном времени.
- Товары выводятся из общего массива `../products.js`.
- Сердечко и кнопка «В корзину» пока оставлены как элементы верстки.
- Чип «Цена от 99 до 2599» и «Очистить» — удаляют фильтр(ы).
- Пагинация — кликабельна, подсвечивает активную страницу.
- Адаптивная верстка (мобильные/планшет/десктоп).

## Файлы

- `index.html` — разметка
- `style.css` — стили
- `script.js` — импортирует общий массив и выводит товары
- `../products.js` — единственный массив товаров
